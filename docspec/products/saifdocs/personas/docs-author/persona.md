# Docs author

A developer or technical writer on a product team who wants AI to write and maintain their documentation. They own a codebase (TypeScript, Python, etc.) and want structured, audience-aware docs — without writing every page by hand.

They care about accuracy (docs must match the actual CLI/API), freshness (docs should re-generate when source changes), and quality (output should read like a skilled human wrote it, not a template dump).

Often arrives via the saifdocs README or via web search. Rarely may arrive via a saifctl docs page after already using saifctl.
