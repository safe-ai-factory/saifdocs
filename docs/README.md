# Saifdocs documentation (source)

This directory holds **published documentation for the Saifdocs product** (the doc generator), distinct from `docspec/` (inputs used to generate SaifCTL / Saifbox docs in the main repo `docs/`).

- Stub pages and `.manifest.json` are maintained here until Saifdocs can generate its own docs from a dedicated docspec.
- Layout mirrors the saifdocs output shape: `references/`, `products/saifdocs/{concepts,how-tos,tutorials}/`, and `products/saifdocs/index.md`.
