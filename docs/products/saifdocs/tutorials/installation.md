# Install saifdocs

By the end of this stage you will have `saifdocs` and [`saifctl`](../concepts/generation-pipeline.md) installed, both CLIs responding on your `PATH`, and everything you need to write your first intent file and generate a page.

---

## Before you begin

- **Node.js 22+** — check with `node --version`
- **pnpm 9+** — check with `pnpm --version`

---

## 1. Install saifdocs

Install `saifdocs` as a dev dependency in the project where you want to generate docs:

```bash
pnpm add -D @safe-ai-factory/saifdocs
```

If you prefer a global install so the CLI is available everywhere:

```bash
pnpm add -g @safe-ai-factory/saifdocs
```

After the install completes, verify the CLI responds:

```bash
saifdocs --version
```

You should see the version number (for example, `0.3.1`). If the command is not found and you used the local install, prefix with `npx`:

```bash
npx saifdocs --version
```

---

## 2. Verify the command surface

Run `--help` to confirm the full command surface is available:

```bash
saifdocs --help
```

You should see the top-level command list:

```
saifdocs gen       Build the full feature tree from docspec/
saifdocs update    Emit a feature tree for stale pages only
saifdocs validate  Report stale pages; exits 1 if any found
saifdocs audit     Report declared pages missing from docs/
saifdocs review    Emit a review feature for a persona/task
```

---

## 3. Install saifctl

`saifctl` is the agent runner that executes each phase in the feature tree `saifdocs gen` emits. Without it, `saifdocs gen` produces a plan but no pages are written.

Check whether `saifctl` is already on your `PATH`:

```bash
saifctl --version
```

If the command is not found, install it globally:

```bash
pnpm add -g @safe-ai-factory/saifctl
```

Verify again:

```bash
saifctl --version
```

---

## Checkpoint

Both CLIs should now respond:

```bash
saifdocs --version    # 0.3.1 (or the version you installed)
saifctl --version     # your installed version
```

You are ready to generate your first documentation page.
